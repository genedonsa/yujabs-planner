이번 달 암호

학원월드 유잡스 커뮤니티 회원 게시판의 '이번 달 암호' 글에서 확인할 수 있어요. 암호는 매달 바뀌어요.

나와 롤모델을 알려 주세요

이걸로 내 경험을 익히고, 롤모델과 비슷한 작은 벤치마킹 채널을 찾고, 내 시리즈마다 터진 영상을 골라요. 모두 나중에 설정에서 바꿀 수 있어요.

찾기 방식 유잡스가 정해요 · 시리즈마다 하나를 골라요

    어떤 방식이든 '그 채널 평소(최근 3개월 롱폼 평균)보다 몇 배'를 따져요. 그래서 그냥 유튜브 검색과 달리, 작은 채널에서 평소보다 크게 먹힌 영상을 찾아내요. 쇼츠와 지난번에 보여 드린 영상은 빼요.

    분석하는 중이에요

    처음엔 5분 안팎 걸려요. 창을 닫지 말고 기다려 주세요.

      롤모델의 영상·키워드로 찾았어요

      벤치마킹 채널 0곳

      구독 리스트의 채널은 분석할 때마다 확인해요

      롤모델 키워드 자동으로 뽑았어요 · 빼거나 더해도 돼요 (다음 분석부터 반영)

      내가 넣은 롤모델

      콘봇이 찾은 작은 벤치마킹 채널 롤모델과 키워드가 겹치고 더 작은 채널

      레퍼런스 영상 0편

      마음에 드는 영상의 기획하기를 누르세요

      영상 만들기

      촬영한 원본 영상(롱폼)을 한 폴더에 넣고 고르세요. 여러 개면 파일 이름 순서대로 이어 붙여요.

      • 말 없는 구간과 '어·음' 같은 추임새를 잘라요
      • 찍다가 "다시"라고 말하면 틀린 부분을 지우고 다시 말한 부분만 남겨요
      • 자막(한 줄 20자, 숫자는 노란색)을 넣고 목소리 크기를 맞춰요

      Claude 앱에 콘봇을 연결했다면 Claude 앱에서 "바탕화면 촬영 폴더 편집해 줘"라고 말해도 돼요. 받아쓰기 오타 고치기·강조 문구·챕터 카드·유튜브 설명란까지 Claude가 해 줘요.

      아직 고르지 않았어요

        처음 한 번은 받아쓰기 모델(약 500MB)을 받느라 더 걸려요. 10분짜리 영상은 보통 5~15분 걸려요.

        다 만들었어요

        '콘봇_완성' 폴더에 최종.mp4와 자막.srt가 있어요. 자막.srt는 유튜브에 올릴 때 자막 파일로 넣을 수 있어요.

        자막·장면 고치기

        자막 글자를 고치거나, 필요 없는 줄은 '빼기'를 누르세요. 뺀 줄은 그 장면도 영상에서 잘려요. 받아쓰기를 다시 하지 않아서 금방 끝나요.

          내 채널·롤모델·키워드는 여기서 바꿔요

          설정

          나

          내 채널·롤모델·경험·링크·시리즈처음에 넣은 입력을 고쳐요

          찾기 방식 유잡스가 정해요 · 시리즈마다 '고치기'에서 골라요

          키워드·구독 리스트

          키워드와 채널벤치마킹 채널 화면에서 빼고 더해요

          Claude 앱 연결

          Claude 앱에서 콘봇 쓰기확인 중…

          연결하면 Claude 앱(회원 본인 계정)에서 "이번 주 급상승 영상으로 기획해 줘", "바탕화면 촬영 폴더 편집해 줘"처럼 말로 시킬 수 있어요. 연결한 뒤 Claude 앱을 완전히 끄고(맥 ⌘Q, 윈도우는 오른쪽 아래 트레이에서 종료) 다시 열어 주세요.

          저장 위치·버전

          자료 폴더홈 폴더의 '유잡스 기획'
          버전

          처음 상태로

          초기화암호·내 채널·롤모델·구독 리스트를 지우고 처음 화면부터 다시 해요

          새 기능이 나왔어요

          받은 뒤 콘봇이 저절로 다시 열려요. 설정·경험·지난 기록은 그대로 남아요.

          처음 상태로 되돌릴까요?

          이번 달 암호, 내 채널·롤모델·경험·시리즈, 키워드, 구독 리스트가 지워지고 암호 화면부터 다시 시작해요.
