# 기획안 요청문

함께 넣은 '이번 주 기획 자료' 파일로, 레퍼런스마다 내 채널용 기획안을 아래 형식(요약 카드형)으로 빠짐없이 만들어 주세요.

## 꼭 지킬 것
- **제목과 썸네일 문구는 레퍼런스 원본을 그대로 한국어로 옮긴다.** 새로 짓지 않는다. 썸네일 문구는 원본 썸네일 이미지(링크 제공)를 보고 확인한다. 원본에 없는 말풍선·문구는 넣지 않는다.
- **썸네일 스타일(글씨 위치·폰트·색·이미지 배치)만 내 채널을 따른다.** '내 채널 조회수 상위' 썸네일(링크 제공)을 보고 공통점을 한 줄로 정리해 쓴다.
- 원본 분석은 '원본 대사 → 한 줄 요약 → 왜 먹혔나 → 내 채널에서는' 순서의 **완전한 문장**으로 쓴다. 화살표(→)나 줄임말로 압축하지 않는다. '상세 분석' 같은 따로 된 요약 목록은 만들지 않는다. 분석은 매칭 카드에만 쓴다.
- 원본 대사는 자막에서 찾아 [시간]과 원문 한 줄(15단어 이내) + 한국어 번역으로 쓴다. 시간에는 https://youtu.be/영상ID?t=초 링크를 단다. 자막이 없으면 '자막 없음'이라고 쓰고 설명란·댓글로 대신한다. 대사를 지어내거나 시간을 짐작해 쓰지 않는다.
- 원문은 한 줄 이내로만 인용한다. 출연자가 스스로 밝힌 수치는 '(본인 주장)'으로 표시한다. 원화로 바꿀 때는 업로드 시점 환율이라고 적는다.
- 내 경험·수치를 지어내지 않는다. 내 경험이 들어갈 자리는 '내 경험 넣기' 질문으로 남긴다.
- 내 시청자가 가진 문제를 해결하거나 가치를 주는 각도만 낸다. 판매 이야기는 영상 마지막 행동 유도에 한 번만.
- '제목 후보'는 만들지 않는다. 제목은 원본 제목 한국어판 하나로 정한다.

## 레퍼런스 1편당 형식

### N. (원본 제목 한국어판)

**원본 영상 vs 내 영상 (나란히)**
| | 원본 영상 | 내 영상 (제안) |
|---|---|---|
| 썸네일 | 원본 썸네일 링크 | 문구 두 줄: 윗줄 / 아랫줄(강조) — 원본 문구 한국어판 |
| 제목 | 원본 제목 (원문) | 원본 제목 한국어판 |
| 정보 | 채널 · 길이 · 조회수 · 업로드일 · 링크 | 예상 길이 · 스타일: 내 채널 인기 썸네일 방식 |

**요약표**
| 항목 | 내용 |
|---|---|
| 유형 · 추천 | 영상 유형(예: 숨은 고수형 / 권위자형 / 사례형 / 방법형) · ★1~3 · 이번 주 몇 순위 |
| 핵심 메시지 | 한두 문장 |
| 타깃 문제 | 내 시청자가 겪는 문제 1~2개 |
| 원본 반응 | 조회수 · 평소 대비 배수 · 댓글 수 · 업로드일 · 출연자 |
| 내 경험 재료 | ○ n · △ n · ✕ n (아래 '내 경험 넣기' 판단 개수) · 핵심 재료 한 줄 |
| 썸네일 문구 | "윗줄 / 아랫줄" (원본 문구 한국어판) |

**원본 → 내 기획안 매칭** — 아래 9개 항목을 **모두** 쓴다. 해당 내용이 원본에 없으면 그 항목에 '원본에 없음'과 이유를 한 줄로 적는다.
1. 썸네일 2. 제목 3. 인트로(첫 1분) 4. 본문 흐름 5. 숫자 쓰는 법 6. 신뢰를 주는 방식 7. 댓글 반응 · 불만 8. 댓글 반응 · 의심 9. 댓글 반응 · 얻어간 것

항목마다 이 모양으로:
- **항목 이름** — 그대로 / 바꿔서 / 줄여서 / 피함 중 하나
  - 원본 대사: [시간](링크) "원문 한 줄" — 한국어 번역 (필요하면 2개까지. 썸네일·제목 항목은 원본 문구·제목, 댓글 항목은 '원본 댓글'과 좋아요 수)
  - 한 줄 요약: 원본이 무엇을 했는지 한 문장
  - 왜 먹혔나: 시청자 입장에서 왜 반응했는지 1~2문장
  - 내 채널에서는: 내 영상에서 어떻게 할지 구체적으로 1~3문장

**내 경험 넣기** — 이 영상을 더 가치 있게 만들 내 경험·숫자를 끌어내는 질문 3~5개
| 판단 | 녹음할 때 답할 질문 | 근거 |
|---|---|---|
| ○ 바로 답할 수 있음 / △ 확인 필요 / ✕ 없음 | 질문 | 자료의 '내 경험 메모'·내 채널 정보 중 근거, 없으면 '메모에 없음' |

**주의·팩트체크** — 본인 주장 수치, 확인이 필요한 사실, 피해야 할 표현

## 마지막에 (4편을 다 쓴 뒤)
1. 4편의 추천 순서와 한 줄 이유
2. 내 경험 질문 중 ○·△ 표시한 것을 모아, 지금 저에게 하나씩 물어봐 주세요. 제가 답하면 그 답을 해당 기획안의 '내 채널에서는'에 반영해 고쳐 주세요.
3. **썸네일 시안용 문구** — 콘봇에 그대로 붙여 넣을 수 있게, 아래 모양으로 편마다 한 줄씩만 따로 써 주세요.
```
1. 윗줄 / 아랫줄
2. 윗줄 / 아랫줄
3. 윗줄 / 아랫줄
4. 윗줄 / 아랫줄
```
