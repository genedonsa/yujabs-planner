# yt-planner 시작하기 (대표님용)

회원이 자기 컴퓨터에서 돌리는 '내 분야 주간 기획' 프로그램의 첫 버전입니다. 설계와 핵심 코드가 들어 있고, Claude Code에서 실제 유튜브로 테스트하며 마무리하면 됩니다.

## Claude Code에서 이어 가기
1. 이 폴더 압축을 풀어 맥의 원하는 곳(예: 문서/yt-planner)에 둡니다.
2. 터미널에서 그 폴더로 가서 `claude` 를 실행합니다.
3. 첫 메시지로 아래를 붙여 넣습니다.

```
CLAUDE.md와 SPEC.md를 읽고 v1을 마무리해 줘.
1) 가상환경 만들고 requirements 설치, tests 통과 확인
2) planner/collect.py를 실제 유튜브로 테스트해서 고치기 (내 채널: https://www.youtube.com/@유튜브-잡스)
3) app.py로 전체 흐름 한 번 돌려 보고 결과 폴더 보여 주기
4) CLAUDE.md의 '알려진 할 일' 순서대로 진행
막히는 결정은 나한테 물어봐.
```

## 매달 암호 바꾸기
- 구글 드라이브 '유잡스' 폴더의 시트 '유잡스 기획 앱 — 이번 달 암호 확인용' A2 칸에 새 암호의 '지문'을 넣으면 됩니다.
- 가장 쉬운 방법: Claude에게 "유잡스 기획 앱 12월 암호를 ○○○로 바꿔 줘"라고 말하면 지문을 만들어 시트에 넣어 줍니다.
- 직접 할 때: `python tools/make_password.py 새암호` → 나온 값을 A2 칸에 붙여 넣기.
- 그다음 새 암호를 커뮤니티 회원 게시판에만 올립니다. 회원 앱은 다음 실행부터 새 암호를 묻습니다.

## 지금 상태
- 오프라인 테스트 7개 통과(암호 확인, 급상승 계산, 키워드, 묶음 파일, 썸네일 합성).
- 유튜브 수집(`planner/collect.py`)은 유튜브 접속이 막힌 환경에서 작성돼 아직 실제로 돌려 보지 않았습니다.
